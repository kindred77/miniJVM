2、miniJVM静态初始化代码开启线程访问静态变量会卡住？

3、miniJVM多线程时，加锁不要使用synchronized代码块的方式，而使用：
Object lock = new Object();
synchronized (lock) {}
否则会有一些奇怪的问题。

4、synchronized里抛出异常会异常阻塞

5、尽量不要使用static{}代码块进行初始化，static{}代码初始化以后再由main函数执行操作可能会有问题。
